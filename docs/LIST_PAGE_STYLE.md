# JustAdmin 列表页样式规范

适用于用户、角色、日志等以查询、筛选和浏览记录为主的后台页面。以用户管理为首个落地示例。颜色、圆角和交互状态沿用 JustAdmin 的 Ant Design 主题，布局规范在浅色、深色及三种导航模式中共用。

## 页面结构

从上到下依次为面包屑、页面头、筛选区、结果区。面包屑由后台布局负责，页面只提供一个一级标题。页面头不套卡片，标题与说明左对齐，新增等页面级主操作在右侧，窄屏时换到标题下一行。说明仅在能帮助理解数据范围或操作规则时出现。

| 区域 | 统一规则 |
| --- | --- |
| 页面头 | 桌面标题 24px、行高 32px，窄屏 20px、行高 28px。说明使用 14px 次要文字。页面级主操作最多一个，有写权限时才展示 |
| 筛选区 | 单独使用轻边框卡片。字段通过占位提示说明用途，控件等高，搜索与重置紧随字段并对齐。搜索为主按钮，重置为默认按钮 |
| 结果区 | 单独使用轻边框卡片，依次容纳可选工具栏、表格、分页。只有存在刷新、导出、批量操作等实际功能时才显示对应入口。结果区无需重复页面标题 |
| 分页区 | 位于表格下方。桌面左侧显示总数，右侧显示页码和每页条数。窄屏允许分两行，上一页、当前页和下一页始终保持在同一行 |

## 尺寸与主题

| 项目 | 默认值 |
| --- | --- |
| 列表内容区左右留白 | 桌面 24px，窄屏 16px。若上层布局已提供该留白，页面不再叠加 |
| 页面头、筛选区、结果区间距 | 桌面 16px，窄屏 12px |
| 卡片内边距 | 桌面 16px，窄屏 12px |
| 筛选字段间距 | 横向 12–16px，换行后纵向 12px |
| 输入框与按钮 | 桌面高度 32px，窄屏主要交互控件建议 40px |
| 表格正文 | 14px。表头高度约 40px，单行数据行最小高度 44px，双行单元格随内容增高 |

背景使用 `colorBgLayout`，卡片使用 `colorBgContainer`，分隔线使用 `colorBorderSecondary`，次要文本使用 `colorTextSecondary`。表头背景、行悬停、控件焦点和状态色沿用 Ant Design 组件 token。使用主题圆角，不为各业务列表单独定义白底、品牌色或阴影。

## 筛选与分页

- 筛选字段使用占位提示，例如「搜索账号或显示名称」「全部状态」。每个控件保留明确的无障碍名称，例如 `aria-label="状态"`。多条件以同一行网格排布，空间不足时按顺序换行。窄屏字段占满可用宽度，按钮组单独成行。
- 默认提交后查询，支持回车提交。搜索、重置和切换每页条数都回到第一页。重置清空筛选条件并保留用户当前选择的每页条数。
- 服务端分页默认 10 条，可选 10、20、50。总数使用服务端返回的筛选后总数。窄屏可减少显示的页码，保留前后翻页和当前页。
- 分页、筛选更新时保留表格区域，在原位置显示加载反馈。保留旧行作为过渡时，加载期间不允许对旧行发起写操作。

## 表格

- 主要识别字段放在左侧，相关字段相邻。文本左对齐，金额和数量右对齐，状态列保持紧凑。操作列放在末尾，链接动作使用明确动词。高风险操作使用危险样式并提供确认。
- 状态同时用文字和颜色表达，例如「启用」使用成功标签，「停用」使用默认标签。长文本可以换行或截断，截断时应能通过鼠标或键盘查看完整值。
- 窄屏优先保留识别字段、关键状态和必要操作。用户列表把账号和显示名称合并为同一个双行单元格，状态保持可见。其余列需要时在表格内部横向滚动，禁止出现整页横向滚动。
- 工具栏或行内操作受权限控制。没有可用操作时隐藏对应按钮或整列，避免留下空列。

## 结果状态

| 状态 | 页面行为 |
| --- | --- |
| 首次加载 | 保留筛选区和表头，在表格主体显示加载状态 |
| 没有记录 | 在表格区域显示「暂无用户」等业务文案。有新增权限且页面支持新增时，可提供对应入口 |
| 筛选无匹配 | 显示「没有符合条件的用户」，提供「重置筛选」，不显示可操作的空分页 |
| 请求失败 | 在结果区显示失败提示和「重试」。保留筛选值及页码，重试当前查询 |

## 验收

1. 桌面 1440px 和 1024px 下，页面标题、两张卡片边缘、表头与分页对齐。三个层级能一眼区分。
2. 窄屏 390px 和 320px 下，账号、显示名称和状态在首屏表格中可见。筛选可操作，分页前后按钮不拆行，页面无横向溢出。
3. 验证浅色、深色和主题色切换，重点检查标签、边框、次要文字和键盘焦点。截图不能替代键盘操作和对比度检查。
4. 验证初次加载、翻页、筛选、重置、空结果及失败重试。管理员和只读账号的操作区都应自然收拢。

## 当前用户列表的落地顺序

1. 桌面先把大标题从卡片中移到页面头，分离筛选与结果卡片，统一字段和表格密度。现有页面的状态标签和真实分页总数可以复用。
2. 窄屏减少重复留白，将账号和显示名称合并，确保状态和翻页一直可见。当前窄屏截图中，状态列在滚动区之外，下一页箭头单独换行。
3. 用用户列表验证规范后，再提取页面头、筛选区和结果区的共享样式。列定义、筛选字段及权限仍由各业务页配置。
